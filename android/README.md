# 原生安卓预览版

版本 `1.8.5-preview`，包名 `com.richangyu.lifeworkbench.preview`。首页、打卡、记录、日程和 AI 确认窗口由 Android 原生界面实现；网页组件只承载授权会话。此版本加入日程日期筛选、关键词搜索和时间排序，并保留手动更新检查和安装帮助，并保留暖白、森林绿、暖橙的原生视觉设计与自有图标。

首次打开填写自己的可信 HTTPS 工作台根地址。公开工程不内置个人服务器、AI 密钥、账号、账本或正式签名；后端需要 `/mobile-connect`、`/api/mobile` 和 `/api/assistant`。授权后读取成功才返回原生页面。

## 日程筛选

“日程”页可切换全部、今天、明天和近 7 天，并搜索标题、地点或备注。日期采用北京时间；近 7 天包含今天及随后六个日历日，跨午夜的有效日程按时间重叠纳入筛选。

仅筛选手机本次已同步的数据，不代表服务器全部历史日程；页面显示匹配条数和已同步条数。搜索词不发往服务器，也不改写日程。按开始时间排序，同一时间保持来源顺序，日期无效的条目在全部视图末尾显示。

切换页面或同步保留当前筛选；更换工作台、重新授权或重启 App 会重置筛选。没有匹配项时可清空筛选，没有已同步日程时保留新增入口。搜索输入最多 100 个字符，延迟 180 毫秒更新结果，避免每次输入重建搜索框。

## 安装与更新

“我的 → 安装与更新”读取 GitHub 公开预发布信息，不发送账号、工作台记录或登录会话。连接失败页面也能查看帮助和检查版本。该功能不自动下载、安装、卸载或申请全局安装权限。

只接受此仓库已发布的预览标签、精确 APK 文件名、官方 HTTPS 下载地址和资产 SHA-256。按数字比较版本，提示签名及安卓版本代码的基本兼容条件。网络失败、限流和安装包信息不足不会显示为“已经是最新版”。发布说明中的签名信息仅供提示，不替代安卓系统对实际安装包的验证。

云端保存成功的记录共用工作台；服务器功能是否同步取决于接口兼容。原生界面和安卓功能升级需要安装新版 APK，不会随着网页自动更新。预览版尚未正式上架应用商店。

## 构建

准备 JDK 17 与 Android SDK 36，设置 `ANDROID_HOME` 或本地 `local.properties`，不得提交本机配置。

```bash
cd android
./gradlew :app:testDebugUnitTest :app:assembleDebug --console=plain
```

Windows 使用 `gradlew.bat`。若中文路径导致测试类加载失败，可复制不含正式签名和网页资产的原生源码至英文隔离目录构建，不删除或跳过检查。APK 输出 `app/build/outputs/apk/debug/app-debug.apk`。公开 CI 独立编译安卓工程，不需要根目录 npm 或 Capacitor。

最低声明 API 22、编译和目标 API 36，不代表所有设备已实测。

## 签名与验证边界

[固定预览签名配置](../docs/ANDROID-PREVIEW-SIGNING.md)与正式签名分开。所有预览签名参数缺省时仍使用开发签名；配置不完整必须失败，不静默回退。公开 CI 在恢复临时密钥前检查隐私边界，固定签名要求公开证书指纹匹配，构建结束清理临时密钥。

配置能力已经加入不代表密钥已配置。CI 和本机开发签名可能不同，不能保证覆盖更新；不要为绕过冲突删除未同步数据。正式密钥不在本轮创建、替换或上传，密码不得写入聊天或源码。

已包含发布策略、北京时间筛选、跨日重叠、搜索和排序的隔离单元测试，实际运行结论以本轮构建记录为准。单元测试、编译和签名检查不等于真机验收。手机安装、授权、键盘布局、AI 写入、跨端同步和实际覆盖更新仍需实测。正式签名、商店账号及上架材料、既有依赖安全告警尚未全部完成。
