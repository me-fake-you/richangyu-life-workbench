# Android native 1.8.21-preview
## 本轮：更清晰的首页与原生交互
- 首页直接显示热量、记录、日程和任务入口；正常同步说明下移，异常状态仍优先显示。
- 已读取的今日安排显示完成环；小屏卡片横向滑动后吸附，大字体保留纵向阅读。
- 最近记录默认显示一条，可展开其余已读取内容。
- 新建日程增加惯性时长滚轮；确认选择只填入表单，需要明确确认才联网保存。
- 有效保存回执通过校验后才显示成功反馈；本机草稿、保存失败和待核对保持原有区分。
- 功能地图采用轻量圆形展开，按系统动画设置降级；不引入网页特效库或新权限。

## 功能与发布边界
原生任务列表仍只读，不创建、删除、完成或修改任务；任务写入升级草稿不包含在本轮。
私人站点权限、数据与接口不变，不增加付费服务，不更改正式签名。
沿用固定预览签名；通过同提交综合检查后才发布，不替换旧版同名资产。
仍待用户实测：覆盖安装、登录、大小字体、日程滑动、滚轮与真实保存反馈。
网页首页另有对应改版；App 界面升级需下载新 APK，网页发布不会自动替换已安装的 App。
遗留依赖风险尚未清零，不把本次交互升级当作全部项目验收或商店正式上架。
