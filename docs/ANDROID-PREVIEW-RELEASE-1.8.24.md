# Android 1.8.24-preview：目标与财务原生管理

## 本批交付
- 目标：原生新建、编辑、起止时间、已存进度、状态；确认完成时仅将该目标设为已完成、进度100%。
- 里程碑：原生新建、编辑、关联目标、时间与完成状态。不自动推算目标进度。
- 账户：新增、改名、类型、初始余额和归档；保留历史。修改初始余额会影响历史计算余额。
- 分类预算：新增、编辑月份、分类、金额与说明；同月同分类唯一，冲突不覆盖。
- 储蓄：新增、编辑目标金额、手动已储蓄金额与时间；不自动转账，不代表银行实际存款。
- 转账：明确选择两个不同的有效账户，确认后仅记录一条转账，不制造收入/支出两笔。
- 已有账目：未关联的收入、支出、转账可以编辑；类型不能转换。软删除只增加删除标记。
- 自身关联或被退款、结算引用的账目，以及拆分、周期关联均不能经普通编辑器修改。
- 目标删除/配色、完整任务关联，票据、退款/报销/借款、周期规则等仍走网页原业务入口。

## 保存安全
所有修改需要明确确认，不自动改写关联日程、工时或财务；财务管理只修改明确核对的对应项目。
登录、同源、预期账号、严格字段、完整版本及数据库原子条件共同保护。可发现同时间戳网页改动。
归档账户、删除目标引用、重复预算及新增退款引用的竞态不会覆盖新数据。
原提交先保存本机再发送；人工核对、重试、放弃使用原编号与原内容。放弃不撤销已保存数据。
财务默认隐藏，使用安全窗口；列表关闭清除。原提交在本机沙箱，不额外加密，不是保险库。
保留固定预览签名与完整CI门禁，不更改正式签名，不新增模型调用、付费资源、后台轮询或站点访问者。
私人接口按匹配源码独立部署，保留仅本人访问和数据，不清空或迁移个人工作台。

## 入口
首页 → 全部功能 → 目标管理 → 管理里程碑。
首页 → 全部功能 → 财务与账本 → 管理账户 / 管理分类预算 / 管理储蓄目标 / 账户转账 / 编辑已有账目。
每页50项，最多1000页；引用选项最多200项，达到上限会提示。搜索只覆盖当前页。
新版原生界面需安装新APK；服务器更新不替换旧界面，同一工作台与账号才共享数据。
