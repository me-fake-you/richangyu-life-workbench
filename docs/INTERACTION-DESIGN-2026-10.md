# 日常屿：页面与交互升级
目标：让记录、饮食、日程、任务和兼职入口清晰，让操作结果可信。
范围：网页 HomeStudio 及安卓原生首页、共享按钮与日程时长选择；不改业务 API、账号权限、签名或数据。

## 设计决策
保留森林绿与浅色纸张品牌；标题、正文、辅助信息分层，数字使用稳定宽度。
常用操作先出现，次要内容可展开；界面不依赖额外动效包，不照搬营销站大标题与动态背景。
只在有明确操作结果或导航变化时反馈；支持键盘、屏幕阅读器及减少动画设置。

## 六种交互的适配
| 参考 | 网页 | 安卓 |
| --- | --- | --- |
| 完成反馈 | 明确区分服务端确认与本机队列 | 校验有效回执后提示；不提前宣称成功 |
| 勾选联动 | 网页任务成功后重新读取并更新完成环 | 安排环仅使用已读取日程状态；不增加原生任务写入 |
| 叠卡展开 | 最近记录展开/收起 | 最近记录展开/收起 |
| 吸附与时间线 | 周日期横向吸附、日程线轻量绘制 | 今日日程卡片原生滑动吸附 |
| 惯性滚轮 | 专注时长滚轮，支持键盘与点击 | 日程快捷时长 NumberPicker，仍需确认保存 |
| 圆形转场 | 进入专注视图轻量展开 | 功能地图轻量展开 |

## 验收
检查类型、现有行为回归、布局状态与减少动画分支；安卓运行单元测试、编译、lint、签名检查。
本机组件测试与流水线成功不等于真机验收；手机体验及跨端保存仍需用户实测。
