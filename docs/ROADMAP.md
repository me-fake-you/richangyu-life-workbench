# 升级路线与验收条件
更新：2026-10-03。以下是计划，不是已完成承诺。

## 第一阶段：让公开源码可靠

- 修复 PR #7 的依赖清单与锁定文件不一致问题。
- 保留锁定安装，不能为通过检查而跳过 npm ci。
- 独立环境完成安装、类型检查、静态检查、测试、编码检查、构建和公开源码导出。
- 增加 AI 日期、预览未保存、确认成功、拒绝未授权金额、重复提交和取消不写入的回归验证。
- 达标后合并；失败项继续保留草稿并公开说明原因。

验收：新环境能按文档复现，完整检查成功，不含密钥或私人数据。

## 第二阶段：真正能在安卓直接使用

- 保持在 App 内完成登录与回流，不把使用过程长期转移到外部网页。
- 明确绑定哪一个工作台和哪个账户，支持重新绑定和退出。
- 今日、日程、记录三个主要入口简洁稳定。
- 完成通知、返回键、文件导入导出和弱网状态的适配。
- 提供正式签名 APK 及校验信息，真机验证安装和更新；版本号要对应实际构建。
- 根据目标商店的规则准备发布资料和审核，不能在审核完成前宣传已上架。

验收：用户可以下载、安装、在应用内登录，完成记录与日程操作；刷新或重启后结果可见，账户隔离正确。

## 第三阶段：更好用的 AI

- 在预览里直接修改日期、时间和文字，再确认。
- 明确显示冲突，并给出候选时间，不擅自移动已有安排。
- 写入失败、超时、限额和联网失败均显示真实状态。
- 普通记录可结合回收站恢复；涉及资金的撤回需要专门审计与结算处理，不能简单删除。
- 增加导出、备份恢复与隐私检查。

验收：同一操作不会重复保存，错误不会显示为成功，撤回不会破坏资金状态。

## 第四阶段：公开体验与反馈

- 独立虚构数据演示，不泄漏生产入口。
- 素材明确区分真实版本截图、概念示意和计划。
- 收集匿名化复现步骤，不索取密钥、原始账本或备份。
- 补拍经验证版本的短视频和安卓真机演示。
