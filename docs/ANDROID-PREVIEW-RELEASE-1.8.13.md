# 日常屿 Android 1.8.13 预览版

此版本仍是预览版，不是商店正式版。真机安装、登录、同步和主要操作必须由实际手机验收；编译或自动测试通过不能替代真机结果。

## 本次更新

- 记录页增加标题、内容和类型的多关键词搜索，以及全部、今天、近七个自然日筛选，日期按北京时间计算。
- 最近记录按时间排序，无法识别的时间明确提示待核对；数量仅表示已加载的记录，不暗示云端完整总数。
- 首页简化未开始的专注卡片，改善较大字体下的布局。
- 新增无需联网的隐私说明入口；清楚说明本地草稿、云端记录、AI 服务和当前尚未完成的账号删除能力。
- 移除已不使用的旧 Capacitor 构建依赖，对旧开发工具的 esbuild 分支作定向修复；依赖安全情况以本版本实际检查结果为准。
- 独立多人基础服务按实际配置报告记录与日程能力，不再把基础空间当作完整 App 后端。
- 补充手机验收清单、交付路线、商店准备与原生构建说明。候选图标仅供后续选用，未替换安装图标。

## 安装和限制

- 包名 `com.richangyu.lifeworkbench.preview`，版本号 `10015`，显示版本 `1.8.13-preview`。
- 公开安装包使用已有固定预览签名，不改正式签名密钥；可否覆盖旧版仍取决于手机原安装包的签名与包名。
- 私人工作台及其权限不变，独立多人服务尚未开放注册，也尚不能作为原生 App 的完整绑定后端。
- 不承诺免费 AI 永久可用，不自动开放私人数据，也不会把本地删除当作云端账号删除。
- 本轮没有提交应用商店审核，没有完成真实手机验收。

## 检查依据

请查看本发布关联提交的 CI、Android Native Preview 和多人基础服务检查结果。安装包必须来自该提交的固定预览签名流水线；本地临时调试包不是正式交付下载。

手机实测步骤见 `docs/ANDROID-PHONE-ACCEPTANCE.md`；完整交付待办见 `docs/DELIVERY-ROADMAP-20261008.md`。
