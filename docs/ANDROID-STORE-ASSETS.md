## Original icon source

Candidate: ../public/brand/android-app-icon-candidate-20261008.svg

This is original editable vector artwork: a forest-green leaf, paper background and
a small warm sun. It preserves the existing product palette without embedding any
account identifier, private domain, external image, font or runtime dependency.

The square 1024 x 1024 viewBox is an authoring canvas, not a claim about a chosen
store's required upload size. The candidate does not replace the installed launcher.
The existing launcher and the store listing remain unchanged.

Before submission, approve the brand candidate, export the target store's required
PNG files, create any required adaptive launcher foreground/background resources,
check safe-area cropping and inspect the actual installed icon on the phone.
Do not present an SVG candidate as an already accepted store icon.

## Store-specific export gate

The application store has not yet been selected. Confirm its current icon, screenshot,
feature-image, text-length and access requirements from that store's official documentation
or account console before exporting final assets. No fixed upload dimensions or number
of screenshots are asserted here.

Required remaining assets and fields:

- Approved raster app icon and any installed adaptive icon resources.
- Genuine native screenshots from the exact submitted build.
- Feature image only if required by the selected store.
- Accurate product name, short description and detailed description.
- Verified support contact, public privacy URL and applicable deletion URL.
- Authorized isolated reviewer access, not the owner's personal login.
- Package/version/signing metadata and the completed phone acceptance results.
