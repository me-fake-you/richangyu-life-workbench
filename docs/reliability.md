# 日常屿长期可靠性指南

日常屿保存的是长期生活资料，可靠性不能只等于“页面能打开”。v1.3 把可靠性拆成五个可以核对的部分：数据库关系、附件原文件、备份可用性、跨设备同步和 AI 运行记录。

## 数据健康分数

“我的 → 数据健康与恢复演练”执行只读检查：

| 检查项 | 通过标准 | 出现问题时 |
| --- | --- | --- |
| 数据表 | 所有模块表可读取并统计 | 先运行部署迁移与环境检查 |
| 数据关联 | 外键检查没有孤立关系 | 下载报告，定位表与记录 |
| 附件 | D1 中的每个 R2 引用都能找到对象 | 从完整备份恢复缺失文件 |
| 最近备份 | 存在且不超过 72 小时 | 创建新的私有云端快照 |
| 同步回执 | 没有未处理的失败和冲突 | 在同步中心重试或人工确认 |
| AI 队列 | 没有长期运行或失败任务 | 查看模型、耗时和错误原因 |

健康分数是运维提示，不是对个人生活的评价。缺少附件和关联问题扣分更多，备份过旧会给出提醒。

## 私有云端快照

快照包括结构化数据清单、照片、票据和资料附件副本，保存在部署绑定的私有 R2 中。每天已有成功自动快照时，重复点击不会制造同日冗余副本。

快照不是公开下载链接，也不会被提交到 GitHub。它仍然依赖当前 Cloudflare 账户，因此需要定期下载完整可移植备份到另一台自己控制的设备。

## 只读恢复演练

恢复演练会：

1. 找到最近成功的自动快照；
2. 读取并解析备份清单；
3. 核对格式、表数、行数和附件目录；
4. 验证每个备份附件副本仍然存在；
5. 计算清单 SHA-256 校验和；
6. 将演练结果加入备份历史。

演练不会把任何行或附件写回正式数据。真正恢复仍然需要在备份中心选择文件、预检冲突并输入明确确认。

## 安全演示模式

演示模式只创建 `demo-v13-` 前缀的虚构数据。内容覆盖生活记录、项目、时间表、表格、财务、兼职、应收、餐食和收件箱，适合第一次体验、截图或录制教程。

重置操作逐表删除同一前缀的演示记录，并要求 `RESET DEMO` 确认。真实记录没有这个前缀，不会进入删除范围。

## 同步诊断

本机离线队列存于浏览器 IndexedDB，云端正式数据存于 D1/R2。同步中心同时显示：

- 本机设备标识与网络类型；
- 待同步、冲突和失败数量；
- 离线附件数量与体积；
- 最早等待时间和最近成功同步；
- 云端累计回执与设备数；
- 最近备份状态。

失败项可以重试；冲突项不会自动覆盖，必须由用户保留云端版本或把本机版本另存为新记录。诊断报告不包含照片二进制原文件。

## AI 透明度

每次后台 AI 任务展示提供方、模型、来源数、基于来源覆盖度的提示性可信度、估算 tokens、费用说明、耗时和是否使用本地回退。可信度不是事实正确率，最终内容仍应回到原始记录或新闻来源核对。
