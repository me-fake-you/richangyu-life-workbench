# 安卓功能入口与迁移边界

适用工程：1.8.20-preview。实际可下载版本以 Releases 成功发布的资产为准。
首页“全部功能”和“我的 → 全部功能与使用入口”可搜索功能名称。

| 功能 | App 内能力 | 当前限制 |
| --- | --- | --- |
| 热量与饮食 | 拍照或手填一餐、营养素、饮水 | AI 图片需服务端显式启用，估算需人工校正 |
| 生活记录 | 原生记录与已读取内容筛选 | 已加载数据不等于完整历史 |
| 日程 | 安排、筛选、历史和分页、详情与本机提醒 | 重复规则完整覆盖与提醒准点性未通过真机验收 |
| 专注打卡 | 原生开始和结束 | 实际手机保存与跨端同步需实测 |
| 兼职与结算 | 项目、工时、应收和实际到账确认 | 完整财务账本仍在网页版 |
| 随手收集 | 原生文字收件箱入口 | 完整整理仍在网页版 |
| AI 助手 | 问答、计划预览与确认 | 需工作台模型配置；免费额度有上限 |
| 本机草稿 | 按账号和工作台隔离、手动提交 | 不自动上传，不等于全部离线功能 |
| 任务中心 | 原生只读列表、搜索、状态筛选和详情 | 最多 100 项；任务编辑和目标管理仍在网页版 |
| 完整财务、目标、相册、表格、情报、回顾、备份、私密空间 | 明确标为网页版 | 不把打开浏览器算成已完成原生迁移 |

首次连接需要自己的可信 HTTPS 工作台根地址，并在 App 内完成授权。
数据能否共享取决于同一工作台、同一账号和兼容接口。
App 界面更新需要新 APK；服务端接口升级不会自动替换已安装的界面。
私人站点不是公共注册入口，独立多人服务尚未开放公共登录。
