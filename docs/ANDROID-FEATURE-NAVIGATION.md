# 安卓功能入口与迁移边界
适用工程：1.8.23-preview。实际下载以成功发布的 Releases 资产为准。
首页“全部功能”和“我的 → 全部功能与使用入口”可搜索名称。

| 功能 | App 内能力 | 当前限制 |
| --- | --- | --- |
| 热量与饮食 | 拍照或手填一餐、营养素、饮水 | AI图片需服务端显式启用，估算需人工校正 |
| 生活记录 | 原生记录与已读内容筛选 | 已加载数据不是完整历史 |
| 日程 | 安排、筛选、历史与分页、详情和本机提醒 | 重复规则完整覆盖及提醒送达待真机验收 |
| 专注打卡 | 原生开始和结束 | 保存、同步仍待真机验收 |
| 兼职与结算 | 项目、工时、应收及到账确认 | 记账入口不会代替结算 |
| 任务中心 | 新增、编辑、完成、搜索、筛选和回执核对 | 前100项；任务关联规划仍需完善 |
| 财务与账本 | 按月分页、历史余额、现有预算储蓄、手动收入支出、回执恢复 | 转账、账户与预算管理、编辑删除、票据、周期规则仍在网页 |
| 目标总览 | 目标进度、关联任务数、最近里程碑 | 只读；目标和里程碑编辑仍在网页 |
| 周期回顾 | 近7/30/90天真实统计和记录标题 | 不含AI长文与财务；只统计已存日程实例 |
| 随手收集 | 原生文字收件箱 | 完整整理仍在网页 |
| AI助手 | 问答、计划预览和确认 | 模型配置和免费额度受服务商限制 |
| 本机草稿 | 按账号工作台隔离、手动提交 | 不自动上传，不代表全部离线可用 |
| 相册、表格、情报、备份、私密空间 | 明确标为网页版 | 不把浏览器跳转算作原生迁移完成 |

每页账目50笔，账户/预算/储蓄各100项；目标100项、里程碑50项。达到限制会提示。
同一可信HTTPS根地址、同一账号和兼容接口才共享数据。私人站点不是公开注册入口。
财务原提交仅在本机应用空间保存，非加密保险库；关闭读取页不清除待核对提交。
