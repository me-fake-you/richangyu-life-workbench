# 安卓功能入口与迁移边界
适用：1.8.24-preview。下载以成功发布的Releases资产为准。
首页“全部功能”或“我的 → 全部功能与使用入口”可搜索。

| 功能 | 原生能力 | 限制 |
| --- | --- | --- |
| 饮食、记录与专注 | 拍照/手填、营养素饮水、写记录、打卡 | AI估算需核对，已读内容不是全历史 |
| 日程 | 新建、筛选、历史分页、详情和本机提醒 | 重复规则与提醒送达待真机验收 |
| 任务 | 新增、编辑、完成、筛选、回执核对 | 前100项，完整关联规划仍在网页 |
| 目标管理 | 新增、编辑、确认完成、进度、起止时间 | 删除、配色和任务关联规划仍在网页 |
| 里程碑 | 目标管理内切换；新增、编辑、关联目标、完成 | 不自动改变目标进度 |
| 财务与账本 | 按月查账、历史余额、手动收支与回执恢复 | 不是银行实时余额 |
| 账户管理 | 财务内入口；新增、改名、类型、初始余额、归档 | 归档保留历史；初始余额影响历史余额 |
| 分类预算与储蓄 | 财务内入口；新增、编辑 | 手动储蓄不自动转账，不代表银行存款 |
| 转账 | 两个账户与金额确认，单条记账 | 不计为收入/支出 |
| 已有账目 | 未关联收支/转账编辑与软删除 | 类型不转换，退款/结算/拆分/周期关联受保护 |
| 兼职与结算 | 项目、工时、应收和到账确认 | 普通记账不代替结算 |
| 周期回顾 | 7/30/90天真实统计 | 不含AI长文、财务或未存日程实例 |
| AI与草稿 | 问答、计划预览确认，隔离草稿手动提交 | 免费额度有限，不自动重发 |
| 相册、表格、情报、备份、私密空间 | 明确标为网页能力 | 浏览器跳转不算原生完成 |

管理列表每页50项，最多1000页；引用选项最多200项。搜索只覆盖当前页。
财务默认隐藏、安全窗口；关页清除列表，原提交仍在应用沙箱直至核对后清理，非额外加密。
同一可信HTTPS根地址、同一账号与兼容接口才共享数据。私人工作台不是公开注册入口。
