# 日常屿 Android 1.8.8-preview：热量与饮食

本版将现有工作台的饮食接口接入原生手机界面，不是跳转网页版。需要安装本版、绑定自己的可信 HTTPS 工作台并完成授权；只更新网站不会自动新增原生 App 入口。

## 在哪里使用

- 首页快捷入口下方：热量与饮食 -> 打开热量与饮食。
- 我的页面：同样提供热量与饮食入口。
- 没有完成登录或绑定时，先连接工作台，不展示假数据。

## 本版范围

- 按手机本地日期查看已加载餐食、热量合计、蛋白质、碳水、脂肪和饮水。
- 手动记一餐，或按餐食文字描述估算；使用现有 /api/nutrition，同网页版共用云端数据。
- 修正已有餐食的营养值，删除需确认；删除也会影响网页记录及关联照片。
- 记录一杯水，设置热量与营养目标；沿用服务器的输入范围，不生成个性化健康建议。
- 保存前持久化待确认标记，超时、服务异常或无效回执不会自动重发；同步并明确核对后恢复操作。
- 返回的数据来源限定为当前绑定 HTTPS 工作台的精确饮食接口，不提取登录 Cookie，不将 AI 密钥放进 App。

## 尚未完成

手机拍照上传与视觉识别、原生食物记忆管理和完整历史导出尚未接入，不应当作本版功能宣传。历史可见范围以现有饮食接口返回的数据为准。后台测试和安装包检查不能替代真实手机的登录、保存与跨端同步实测。

热量和营养素仅用于日常记录，估算不是精确测量，手动目标和默认值不是个性化营养或医疗建议。未知宏量营养素留空会按 0 保存，不代表食物实际没有该营养素。
