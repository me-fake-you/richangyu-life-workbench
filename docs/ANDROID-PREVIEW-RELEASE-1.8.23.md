# Android 1.8.23-preview：原生账本、目标总览与周期回顾

## 使用入口
首页 → 全部功能 → 财务与账本 / 目标总览 / 周期回顾。需要兼容的私人工作台接口和同一账号。
原有任务新增、编辑、完成及首页交互保留。原生界面需要安装本版 APK，网页更新不会替换旧 App 界面。

## 财务与账本
- 选择北京时间月份，每页50笔，可前后翻页；账户余额按全部未删除历史计算，不只按已显示列表计算。
- 查看现有账户、分类预算、储蓄目标，分别最多100项；达到上限会提示，不把截断列表当作完整账本。
- 默认隐藏金额与账目详情，主动显示才展开；财务弹窗启用安全窗口，关闭清除本次读取列表。
- 手动新增收入或支出，需要明确确认。金额最多两位小数，精确转换为分；账户必须仍存在且未归档。
- 新增账目不代表兼职到账确认，不改变应收或结算；兼职收入请在原结算入口核对，避免人为重复记录。
- 回执按服务端账号隔离。先持久保存原提交，再发送；断网、关闭和授权变化不自动重试。
- 核对、重试或放弃使用原编号。放弃不撤销已保存账目；服务器原子回执防止迟到提交重复记账。
- 本机原提交位于应用沙箱，不宣称加密保险库；不要卸载或清空数据来处理待核对提交。
- 账户管理、转账、账目编辑删除、预算与储蓄编辑、票据和周期规则完整管理仍在网页版。
- 收入/支出统计仅同名类型，不含转账、借款、退款和报销。预算按分类统计支出、预付款、应付；银行真实余额需自行核对。
- 读取不会补记周期账单或修改账目。保留现有站点初始化机制，不迁移或清空个人数据。

## 目标与回顾
- 原生查看目标已存进度、关联任务完成数及最近里程碑。进度不自动从任务数推算；完整编辑仍在网页版。
- 近7、30、90个北京时间自然日的记录、活跃天数、已完成任务、已存日程实例计划/实际分钟及已结束兼职时长。
- 排除私密、删除及进行中的打卡；不推断尚未生成的重复日程，不把计划分钟当成实际投入。
- 回顾为确定性统计，不调用AI，不读取财务，不自动保存新总结。AI长文、完整历史分析仍在网页版。
- 账号、来源、范围和回执都需核对；读取失败显示失败，不显示成零数据。

## 检查与交付边界
固定预览签名、完整CI门禁和不可变版本发布保持不变；不更改正式签名。
保留任务确认保护：不自动改写关联日程、工时或财务。
私人接口随匹配源码独立部署，保留仅本人权限；不是多人注册或商店上线。
