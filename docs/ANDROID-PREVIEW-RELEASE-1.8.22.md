# Android native 1.8.22-preview

保留 1.8.21 的首页、滑动、滚轮、动效和减少动画适配。

## 本轮：任务中心可操作
入口：首页 → 全部功能 → 任务中心。
支持新增、编辑和标记完成；可设置优先级、预计分钟及北京时间截止日期。需要明确确认才提交。
不自动改写关联日程、工时或财务；没有删除任务功能，目标管理仍在网页版。
与网页任务共享同一私人工作台数据，需要对应服务端任务操作接口。

## 防重复与冲突处理
- 每笔提交先在本机应用空间保存原编号和内容，再发送请求；不是加密保险库，不会自动上传或重试。
- 服务端按账号和原内容核对回执，同一提交重试不会创建第二笔任务。
- 编辑与完成校验完整内容版本；网页已修改或发生竞争时返回冲突，不强行覆盖。
- “核对上次提交”没有找到回执不代表保存一定失败。可手动重试原请求。
- “放弃这次提交”阻止未完成的原提交继续保存；已保存则返回原结果，不撤销任务。
- 关闭页面保留待核对提交；换账号或工作台不会发送旧空间的提交。
- 列表仍最多 100 项，不缓存完整离线任务列表。旧版 App 的只读接口保持兼容。

## 验收与发布边界
仍待用户实测：手机安装、授权、创建/编辑/完成、网页同步、断网恢复及账号切换。
沿用独立预览签名，不更改正式签名。不是应用商店正式上架版本。
同提交综合检查通过后，流水线才发布安装包。签名与摘要以发布资产为准。
私人站点维持原权限；公开多人服务尚未开放，不新增付费模型或服务。
依赖审计遗留 8 项 high、0 项 critical（生产依赖 0）；本轮不宣称全部依赖已无风险。
