# 安卓 1.8.4 预览版安装与更新

本版为可下载的原生安卓预览包，新增手动更新检查、签名兼容提示与安装帮助。打卡、记录、日程和 AI 仍使用原有原生界面与工作台接口；网页只用于登录授权。此发布不是应用商店正式版，也不是手机端全部流程已经验收的证明。

## 下载和安装

用手机浏览器打开 [1.8.4 官方发布页](https://github.com/me-fake-you/richangyu-life-workbench/releases/tag/v1.8.4-preview)，下载 `life-workbench-v1.8.4-preview.apk`。包名 `com.richangyu.lifeworkbench.preview`，安卓版本代码 `10006`，目标 SDK `36`。

微信内不能安装时，选择在手机浏览器打开。若文件被附加 `.1`，仅在确认来源为官方 APK 后恢复 `.apk` 扩展名。不要将任意未知文件改名安装；只为可信下载来源授权安装，不关闭全局安全防护。

先核对重要内容已成功保存至云端。若安卓提示签名不一致，不能直接覆盖安装；不要立即卸载，以免丢失本机未保存输入和 AI 草稿。查看该发布的实际签名信息后再决定处理方式。旧版发布保留，不替换同版本安装包。

## 首次使用

填写自己的可信 HTTPS 工作台根地址，进入授权页登录。成功读取数据后返回原生页面；没有绑定、登录失败或服务器接口不兼容时，不会凭空显示云端记录。公开客户端不内置私人地址、AI 密钥或个人数据。

服务器需支持 `/mobile-connect`、`/api/mobile` 和 `/api/assistant`。原有 AI 草稿确认、金额单独授权和待核对保存防护保留，不绕过确认直接写入。

## 本轮变化

- “我的 → 安装与更新”显示当前版本，手动检查 GitHub 已发布的预览版。
- 按数字比较版本，只接受此仓库的精确 APK 文件名、官方地址、合理大小与 SHA-256 资产摘要。
- 下载前提示包名、签名和版本代码是否满足覆盖安装的基本条件；最终以安卓安装器为准。
- 连接失败页面也提供安装帮助和更新入口，不要求先登录。
- 网络错误、限流或发布信息不完整与“没有发现新版”分开显示。
- 浏览器中手动下载，不自动安装、卸载或申请额外安装权限。
- 增加可选固定预览签名配置与 CI 证书指纹检查，不触碰正式密钥。

## 会不会随工作台更新

已成功保存的云端记录共用同一工作台。服务器功能是否同步取决于接口兼容；安卓原生界面和功能需要安装新 APK。旧 App 不会自动获得本次更新入口，需先安装此版本。

固定签名配置能力不等于已启用。公开构建会在文末写入该包实际的公开证书指纹、版本代码和签名模式；没有固定预览密钥时，仍不能保证下次可直接覆盖。发布元数据仅供提示，不能代替实际 APK 的校验。

## 检查范围和剩余工作

本轮 CI 运行新增策略测试与现有原生测试，编译 APK，并检查包名、版本、目标 SDK 和签名后发布；实际结果以对应 Actions 运行状态为准，不预先宣称成功。

真机安装、授权返回、打卡、AI 确认写入、跨端同步、手机布局和实际覆盖更新尚待实测。正式签名、商店账号与材料、剩余依赖安全告警尚未全部完成。预览版不代表已上架或整体安全验收。
