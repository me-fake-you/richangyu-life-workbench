# 安卓 1.8.6 首次绑定引导预览版

本版解决首次打开时“没有工作台地址”却显示为“连接失败”和“正在连接”的混淆，新增清晰的原生首次使用引导、点击粘贴地址和连接前域名确认。打卡、记录、日程筛选、AI 草稿确认、云端同步及更新检查保留，服务器接口和私人工作台不在本轮修改。

## 下载与安装

从 [1.8.6 官方发布页](https://github.com/me-fake-you/richangyu-life-workbench/releases/tag/v1.8.6-preview) 下载 `life-workbench-v1.8.6-preview.apk`。包名 `com.richangyu.lifeworkbench.preview`，版本代码 `10008`，版本 `1.8.6-preview`，目标 SDK `36`。

使用手机浏览器下载。微信内不能安装时选择在浏览器打开；仅在确认文件来自官方 APK 后，才恢复被附加 `.1` 的 `.apk` 扩展名。不将未知文件改名安装，不关闭全局安全防护。

公开预览签名可能与旧包不同，不能保证覆盖安装。不要为绕过冲突立即卸载，先核对重要内容已成功保存到云端；本机输入和草稿可能丢失。旧版发布保留，不替换同版本产物。

## 第一次连接

1. 未绑定时，首页显示首次使用引导，右上角显示“待绑定”，不会自动弹出输入框或显示服务器连接失败。
2. 点击“绑定我的工作台”。从自己已有的工作台复制可信 HTTPS 根地址，手动填写或点击“粘贴工作台地址”。
3. 不填邮箱、密码、API 密钥、登录路径或带参数的授权链接。输入框仅接受单个根域名地址。
4. 点击“连接”，核对确认窗口中的目标域名，再点击“确认连接”进入原有授权流程。
5. 用工作台账号登录。只有授权并读取到有效数据后才返回原生打卡、记录、日程和 AI 页面。

“暂不连接”返回引导页，状态仍是待绑定。有地址但尚未授权时显示“等待授权”；真实网络或数据错误仍按原有错误流程处理。本版不自动登录，不绕过权限，不创建演示记录。

服务器需支持 `/mobile-connect`、`/api/mobile` 和 `/api/assistant`。未配置、授权失败或接口不兼容都可能导致没有云端内容，不能仅凭截图判断登录和同步已经通过。

## 剪贴板与地址保护

- 启动、返回页面和填写地址不会自动读取剪贴板；只有点击粘贴按钮时读取第一项文本。
- 不展开 URI 剪贴板项目，不把任意文件或其他内容转换为地址。
- 粘贴成功只填入规范化地址，不自动发起网络请求；首次绑定和更换域名均需确认。
- 输入最多 300 字符，使用现有 HTTPS 根地址安全策略，拒绝非 HTTPS、非根路径、参数、用户凭据、IP 或本地地址，以及内部多行、隐藏控制字符和过长内容。
- 不显示、记录或上传剪贴板原文。确认连接后，目标工作台才会按现有流程接收授权和数据操作。
- 公开客户端不内置私人服务器地址、AI 密钥或个人数据，不读取或更换正式签名密钥。

## 更新和验证边界

原生引导变化需要安装新版 APK，不会随网页自动更新。固定预览签名的配置能力保留，但不代表已经配置；文末元数据记录此包实际证书和签名模式。固定预览签名配置见 [说明](https://github.com/me-fake-you/richangyu-life-workbench/blob/codex/workbench-ai-20261002-c258dd87/docs/ANDROID-PREVIEW-SIGNING.md)。

本轮新增绑定输入与初始状态的隔离测试，覆盖空输入、规范化、非法目的地、多行与隐藏控制字符、长度上限和未绑定状态。CI 执行原生测试、编译、隐私边界、包名版本和签名核对后发布，实际结果以对应 Actions 运行状态为准，不预先宣称成功。

此前手机截图只证明 App 可以打开并显示未绑定，不能证明登录和同步已通过。新版粘贴按钮、域名确认、手机键盘和授权返回仍待真机实测；打卡、AI 确认写入、跨端同步与覆盖安装尚未全部验收。

目前是开发签名预览版，未正式上架。固定签名、正式签名、商店账号与材料、剩余依赖安全告警尚未全部完成。自动检查成功不代表整个最终交付目标完成。
