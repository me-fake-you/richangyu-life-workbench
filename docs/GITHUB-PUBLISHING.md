# GitHub 发布与隐私边界

GitHub 存放应用源码，不是个人工作台数据备份。公开源码不代表公开线上工作台。

## 不应上传

- API 密钥、访问令牌、验证码和真实环境变量文件。
- 数据库、个人导出、照片、聊天记录、账本、备份与上传附件。
- 安卓签名文件、签名密码、未脱敏的安装配置。
- 本机路径、服务器绑定凭据、生产资源配置以及部署归档。
- 依赖目录、构建输出、运行日志和包含旧凭据的 Git 历史。

## AI 配置

在服务器的环境变量管理中设置以下值，不放进网页代码或安卓安装包：

```dotenv
AI_PROVIDER=groq
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_MODEL=openai/gpt-oss-120b
GROQ_API_KEY=YOUR_SERVER_SIDE_KEY
```

这里的密钥只是占位符。免费服务有额度限制，模型名称和服务政策可能变化，以提供商为准。

## 发布方式

升级使用独立分支及合并请求，不强制覆盖已有主分支。保留原有仓库可见性，改变公开或私有属性前由所有者确认。
如果只发布线上版本快照，应明确其独立目录和部署前提，不覆盖已有安卓工程。
部署需要自行配置身份认证、持久化数据库及附件存储；源码公开不会赋予他人访问原工作台数据的权限。

不得把本轮源码发布称为新的 APK、应用商店上架或真实保存测试已完成。
