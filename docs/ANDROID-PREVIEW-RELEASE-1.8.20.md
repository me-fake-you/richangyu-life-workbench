# Android native 1.8.20-preview

此版本新增原生只读任务中心，不是网页版完整功能已全部迁移的声明。
下载版本以本仓库成功发布的 Release 和实际 APK 资产为准。

## 在手机上怎么找到

首页“常用功能 → 全部功能 → 任务中心”，或“我的 → 全部功能与使用入口”。
可查看任务详情，按待办、今日重点、逾期和已完成筛选，
搜索标题、说明、项目和优先级。编辑任务与目标管理仍在网页版。

## 数据和连接边界

- 使用当前已绑定工作台的授权会话，接口为只读 `/api/mobile-tasks`。
- 读取前和响应后校验账号范围；切换工作台、重新授权或销毁页面时清空页面数据。
- 最多读取排序后的 100 项，截断时明确提示；筛选只针对本次读取的任务。
- 截止时间以北京时间显示，不依赖手机当前时区。
- 不提供离线缓存，不自动上传内容，不创建、删除、完成或修改任务。
- 工作台需先部署兼容读取接口；404、未登录和读取失败不是“没有任务”。

## 包名与更新

包名 `com.richangyu.lifeworkbench.preview`，版本代码 `10022`，
最低声明 API 22，目标 API 36。沿用固定预览签名，不更改正式签名。
旧 Release 与安装包不覆盖；系统仍会验证实际签名能否覆盖安装。

真实手机安装、登录、任务读取、账号切换、大字体布局和覆盖更新仍待用户实测。
网页构建、单元测试和 APK 编译不替代这些结果。尚未上架应用商店。
