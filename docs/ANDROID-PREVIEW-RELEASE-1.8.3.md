# 安卓原生界面预览版 1.8.3

这是日常屿生活工作台的安卓预览安装包，重点升级原生页面的视觉层次与操作入口。它不是网页版快捷方式，也不是应用商店正式版。

## 本轮界面变化

- 首页使用暖白背景与森林绿专注卡片，突出开始打卡和结束保存。
- 底部导航增加统一线条图标与选中状态。
- 快捷入口支持打开 AI 助手、新建记录、新建日程和收件箱收集。
- 日程使用日期侧栏，按服务端返回顺序显示日期分组，时间统一为北京时间。
- 记录显示类型、时间、内容摘要，点击后查看完整内容。
- AI 输入优先显示，对话使用消息气泡，日程参考和金额授权折叠在可选设置中。
- 草稿警告与保存按钮保留，AI 不会绕过确认自动写入。
- 新增统一原生样式组件、应用图标和启动标志，无额外图片或字体下载依赖。

## 安装和连接

1. 在手机系统浏览器中下载以 .apk 结尾的文件。若文件被聊天工具追加 .1 等后缀，先恢复 .apk 后缀。
2. 按手机系统提示为当前下载来源临时允许安装，安装后可关闭该权限。
3. 首次打开填写自己可信的 HTTPS 工作台根地址，不填写密码、验证码或 AI 密钥。
4. 在 App 内完成账号授权。授权页面用于建立会话，打卡、记录、日程和 AI 操作使用原生页面。
5. 保存成功并联网同步后，手机与该账号的工作台读取同一份云端数据。

本预览版采用调试签名，与旧预览包的签名可能不同。若系统提示签名不一致，请先确认重要记录已经保存到云端，再卸载旧预览包并重新安装。卸载会清除本机登录、设置和未保存的输入；不要把卸载当作数据备份方式。

## 检查范围和限制

构建和单元测试结果以对应 GitHub Actions 记录为准。编译、单元测试与安装包检查不能替代手机实测。

真机安装、授权返回、打卡保存、AI 确认写入和电脑手机同步仍需实测。当前版本不是已上架产品，也未声明通过应用商店审核。正式签名、商店材料和剩余依赖安全问题需要继续完成。

目前已安装的旧版 App 不会自动获得这些本地原生界面改动，需要安装新版本；工作台云端数据通过联网同步获取。
