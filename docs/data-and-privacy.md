# 数据与隐私

更新：2026-10-08。适用于源码的数据处理说明，**不是所有自部署实例通用的运营隐私协议，也不代表商店审核已经通过**。正式公开服务还需填写实际运营主体、隐私联系方式、模型提供方、数据地域、保留期限和删除流程。

日常屿可能处理日记、照片、日程、营养估算、财务和兼职信息。请分清安卓 App、本地浏览器、绑定的服务和模型提供方四个边界。

## 登录与他人使用

个人工作台的数据按整个部署保存，登录成功不等于每个账号自动拥有独立空间。设备 ID、显示邮箱、私密标记和平台页面访问授权都不能替代逐项服务端权限。

个人部署应保持受限访问范围。分发 APK 不会授权其他人使用你的私人数据。不要分享个人账号、授权链接、API 密钥或私人站点地址。

独立多人服务已有服务端账号归属和空间隔离基础，但独立部署、公开账号流程、安卓接口覆盖及两账号实测仍待完成。不能把这份基础源码描述为已经开放注册的产品，也不能让多人接口回退到个人工作台数据。

## 安卓端的数据流

| 内容 | 本机或服务位置 | 实际边界 |
| --- | --- | --- |
| 工作台根地址、随机设备 ID、必要状态 | App 私有 SharedPreferences | 用户主动绑定；随机 ID 不是 IMEI，也不是权限隔离机制 |
| 登录 Cookie 与授权页面存储 | App 内系统 WebView | 由绑定服务及其身份提供方参与登录；可能在再次打开时保留 |
| 账号和工作台分区的草稿 | App 私有 SharedPreferences | 手动保存、手动提交；没有额外的草稿内容加密，不是端到端加密 |
| 已同步记录、日程等 | 绑定工作台与当前页面内存 | 原生页面从受保护接口读取；搜索只筛选本次快照，不宣称搜索全量云端 |
| 餐食照片临时副本 | App 私有缓存与处理内存 | 只处理明确选择的文件；正常处理结束会清理临时副本，异常中断可能留下缓存 |
| 保存后的餐食、记录、打卡或兼职信息 | 绑定工作台的数据库及附件存储 | 只有确认保存的内容才应被视作云端记录；超时先核对再重试 |
| AI 请求和选定的上下文 | 工作台及其配置的模型提供方 | 用户触发 AI 功能；模型预览不是写入授权 |
| 手动更新查询 | GitHub 公开发布服务 | 网络服务可能处理连接元数据；不把工作台正文放进版本查询 |

草稿的账号分区是访问边界，不等于内容加密。不要把 App 私有存储或 HTTPS 写成零知识保证。清除应用数据、卸载或更换设备可能丢失尚未提交的本机内容。

## 照片与系统权限

当前安卓源码清单声明网络权限，未声明通讯录、短信、定位、整相册读取或直接相机权限。最终发布时仍需检查合并后的清单和实际第三方依赖，不能仅凭源码清单认定完整 APK 的权限。

餐食照片通过系统相机或文件选择器选取，拍照使用临时文件的 URI 授权；不会遍历整个相册。上传前会缩放、重新编码并移除原始 EXIF 元数据与文件名，但图片画面本身仍可能泄露身份、环境或账单内容。

应用正常路径会清理本次创建的临时文件，不删除相册源文件。系统相机、文件提供方及云端保存的副本有各自的数据处理边界，不能承诺所有副本都随本机临时文件一起删除。

## 网页与默认 Cloudflare 部署

| 数据 | 默认部署位置 | 说明 |
| --- | --- | --- |
| 记录、日程、表格、财务、总结 | Cloudflare D1 | 结构化数据与关联，实际配置由部署者负责 |
| 照片、语音、附件、票据、归档 | Cloudflare R2 | 数据库保存对象键和元数据 |
| 浏览器离线待同步内容 | 当前设备浏览器 | 与安卓本机草稿不同；清理浏览器数据可能丢失 |
| API 密钥 | 本地环境文件或服务端 Secret | 不应进入公开仓库、客户端包或反馈截图 |
| AI 请求 | 部署者选择的模型服务 | 服务条款、日志、地域及保留期限需逐提供方核查 |

绑定任意 HTTPS 地址并不能证明其部署可信。自托管时必须保护每个 API 和附件读取，不能只给网页加登录。数据库和对象存储管理员可能读取底层数据；当前不能宣称端到端加密。

## AI、营养与财务边界

模型可能接收用户问题、主动选择的记录片段、标签、日期、日程上下文或用于识别的餐食图片。可选后台总结任务的数据范围也应由部署者披露。私密记录是否排除，需要针对实际版本和接口核查，不能用一个界面标记代替验证。

供应商的收费、训练用途、保留期限与数据地域以当前服务配置和条款为准，不承诺永久免费、无限额度或零保留。不要提交密码、身份证件、无关支付凭证或客户完整联系方式。

AI 预览必须经过用户核对与确认，取消不应触发写入。营养估算必须允许人工修正，不可替代医学诊断或专业营养建议。工时、应收、实际到账与账户交易应分别记录，不能因为工作了一小时就自动登记收入。

## 退出授权、本机删除、云端删除

- 重新授权、更换工作台或清除登录 Cookie，不等于注销服务账号或删除云端记录。
- 退出授权不会自动删除本机草稿；清除 App 数据或卸载也不会删除服务器数据库。
- 删除单条草稿只影响该账号分区的本机草稿，不能作为账号注销证明。
- 当前未交付统一的安卓账号注销和云端删除入口；不要在商店表单中填写“已提供”。
- 正式多人服务需完成受身份保护的注销请求、关联数据处理、附件清理、回执及必要保留项披露。
- 备份、日志和第三方模型服务可能有单独的保留政策，实际期限尚待运营者明确。
- 对外提供删除或恢复承诺前，需用受控账号验证完整流程。不要通过清空正式数据库代替单账号删除。

## 正式发布前的隐私资料

运营者需确定公开联系方式与有效政策地址，不能擅自把个人邮箱用作对外支持邮箱。正式政策应准确覆盖全部实际服务与第三方 SDK。

若选择 Google Play，应用内隐私说明与商店链接都需准备；启用应用内账号创建时，还需应用内及外部网页的账号删除路径。详见 [Google Play 用户数据政策](https://support.google.com/googleplay/android-developer/answer/10144311)及[账号删除说明](https://support.google.com/googleplay/android-developer/answer/13327111)。

本页属于准备资料，不替代具体地区、具体商店及实际运营服务的审查。

## 公开仓库与反馈安全

禁止提交真实环境文件、密钥、签名私钥、生产数据库、备份、照片、票据、客户资料、授权链接或个人部署配置。Base64 不是秘密保护方式。

分享截图或日志前遮住邮箱、私人域名、记录正文、金额、姓名、电话、地址和对象 URL。公共问题反馈只描述复现步骤，不贴私人内容。示例资料必须使用明确标注的虚构数据。

手机操作与同步验收见[安卓手机验收](ANDROID-PHONE-ACCEPTANCE.md)，正式发布准备见[商店准备清单](ANDROID-STORE-PREPARATION-20261003.md)。
