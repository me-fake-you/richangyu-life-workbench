## 收到 APK 后怎么安装

1. 只安装你信任来源提供的文件。文件名必须以 `.apk` 结束；若传输工具变成 `.apk.1`，需恢复正确后缀，重命名不会修复损坏的文件。
2. 用安卓文件管理器打开，按系统提示为当前可信来源授予安装权限，不需要关闭手机的安全防护。
3. 预览版单独安装，不覆盖旧正式版；它不能用于证明正式签名包支持覆盖升级。
4. 授权只应使用有权访问对应工作台的账户。出现授权拒绝时不要尝试绕过权限。
5. 在真机确认登录能返回 App、列表可以同步后，再核对写入功能。不要把私人账目当作演示数据。

## 公开发布前必须补齐

- 明确面向作者个人还是其他自行部署的用户，通用版需要用户自行绑定自己的工作台。
- 使用原正式签名材料验证升级；不重新生成密钥替代原有签名。不要上传密钥或密码。
- 完成安装、授权返回、只读同步、返回键、弱网和保存结果检查。
- 先用独立虚构数据测试记录、打卡和日程写入，再公开验收范围。
- APK / AAB 发布与应用商店上架是不同流程；上架还需要开发者账户、隐私说明及商店审核。
