# 生活工作台 Android 1.8.2-preview

开发预览版，不是应用商店正式版。尚未完成真机安装、授权登录、AI 保存、同步和升级验收。

## 本版内容

- 原生首页、打卡、记录、日程和 AI 对话 / 草稿确认。
- 首次启动绑定自己的可信 HTTPS 工作台，不内置个人服务器或 AI 密钥。
- 草稿由用户确认后保存，可选择日程上下文；金额信息单独同意，草稿有有效期，不自动重发保存。
- 授权仍使用应用内网页会话，身份提供商的手机兼容性需要实测。

本地隔离构建通过 9 项单元测试、APK 编译和开发签名验证。公开下载只在独立 Android CI 检查通过后发布；这些检查不是端到端验收。

## 安装与更新

在手机浏览器下载 `life-workbench-v1.8.2-preview.apk`，通过系统安装器安装可信来源包。聊天工具可能改名为 `.apk.1`，必要时恢复 `.apk` 后在文件管理器打开。首次启动填写自己的工作台根地址并授权。

公开包使用 CI 开发签名，可能无法覆盖本机旧预览包。不要为绕过签名冲突删除未同步数据。正式版需稳定签名、商店账号和发布材料；不上传签名文件、密码、私有数据库或生产配置。

兼容的云端数据更新可在同步后读取；新增原生页面或系统功能仍需更新安装包。图标暂为生成模板。

完整依赖审计仍有遗留告警。私人线上服务没有在本轮部署，不宣称已经上架商店。
