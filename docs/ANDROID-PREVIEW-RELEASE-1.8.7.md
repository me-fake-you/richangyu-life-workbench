# 安卓固定签名预览版

版本 `1.8.7-preview`，版本代码 `10009`，包名 `com.richangyu.lifeworkbench.preview`。这是开发预览版，不是应用商店正式版。

本轮不继续堆界面功能，重点是固定后续预览版签名、首次安装迁移说明和真机验收。保留 1.8.6 的绑定引导、粘贴地址与域名确认，以及原生打卡、记录、日程和 AI 草稿确认流程。

## 更新内容

- 公开发布要求完整固定预览密钥，缺少配置时停止，避免再次发布随机开发签名。
- 预览签名与正式签名独立保管，公开证书指纹必须与 APK 实际签名一致。
- PR 验证不读取签名秘密，不发布下载版；固定签名只用于可信分支的发布构建。
- 新增 Windows 私下准备签名和同机备份工具，不输出私钥或密码，不覆盖已有密钥。
- 补齐真机验收和他人使用说明，明确登录授权不等于逐账号数据隔离。

## 安装与更新

与此前随机签名的预览版不同，首次迁移通常不能覆盖安装。不要直接卸载旧版，先核对重要内容已经保存到工作台，并妥善保留本机未保存输入和草稿。之后版本只有在同包名、同密钥且版本代码递增时才具备覆盖更新条件，仍需真实手机验证。

下载后在手机上绑定自己可信的兼容 HTTPS 工作台根地址，核对域名，完成授权并确认返回原生首页。不要填写回调链接、密码或 API 密钥。工作台网页更新不会自动改变原生 App 的界面代码。

## 他人使用

公开安装包不固定绑定个人站点。其他人可绑定自己独立部署的兼容工作台，但当前工作台不是已经开放注册的多用户云服务；其记录和日程按工作台共用，不按账号隔离。个人部署仍保持原访问范围，不为试用者公开个人数据。

## 验证边界

发布流水线执行原生单元测试、编译以及 APK 包名、版本和实际签名检查。具体成功结果以对应 Actions 为准。电脑检查不证明手机登录、打卡、AI 确认保存、跨端同步和覆盖更新已通过；这些项目必须按 [手机验收清单](https://github.com/me-fake-you/richangyu-life-workbench/blob/codex/workbench-ai-20261002-c258dd87/docs/ANDROID-PHONE-ACCEPTANCE.md) 实测。

正式签名未改动，未提交商店审核。预览固定签名不代表正式商店签名已就绪，也不代表所有历史依赖安全告警已修复。私钥、密码、个人地址和记录不进入公开源码或 APK。
