# AI 发布检查修复与依赖安全评估

日期：2026-10-03

## 本轮范围

仅修改公开 AI 开发分支，不部署私人工作台，不写入真实日程、生活记录或资金数据，不上传私人 APK、密钥、数据库、签名材料或账户信息。

- 将助手打开、范围切换和重试的加载状态放到用户操作中，不在 Effect 中同步设置加载状态。
- 使用具有明确依赖的异步加载回调，保留中止逻辑，过期响应不会覆盖较新的状态。
- 读取状态期间暂停提交，并显示明确的读取提示；保留金额授权、预览确认、签名和服务器身份校验。
- 固定捕获关闭后返回的焦点目标，不在清理阶段读取可能已经改变的按钮引用。
- 五个旧测试保留全部功能、安全和文档断言，只将写死的 1.5.0 版本改为至少 1.5.0 的正式语义版本。
- 新增版本兼容测试，拒绝旧版本、预览标记、格式错误及超出安全整数的版本值。
- 没有跳过锁定安装、关闭 React 检查、删除测试或强制升级依赖。

[React 加载状态规则](https://react.dev/reference/eslint-plugin-react-hooks/lints/set-state-in-effect)说明为什么不能在 Effect 中同步设置加载状态。请求结果到达后的状态更新仍保留。

## 官方审计结果

审计使用 npm 官方 registry，仅针对公开依赖信息；不改变全局配置，不执行依赖安装脚本。镜像 registry 的安全端点返回不支持，因此不能把镜像审计失败当作没有漏洞。

| 范围 | 记录总数 | 严重 | 高 | 中 | 低 |
| --- | --- | --- | --- | --- | --- |
| 完整锁定依赖 | 33 | 2 | 24 | 6 | 1 |
| 排除 dev 的安装分类 | 5 | 1 | 3 | 1 | 0 |

这些是审计聚合记录，不等于同等数量的独立、已可利用的工作台漏洞。审计没有验证实际攻击入口，也没有证明发生过入侵。排除 dev 不代表构建工具或编译后产物中包含的代码绝对不会进入部署。

## 优先处理项

- Next.js 当前锁定版本位于审计受影响范围，生产依赖分类仍存在严重记录。有关 Node.js ImageResponse 的公告需要特定输入与运行方式，不能据此直接断言私人 Cloudflare 部署可被利用。[维护方公告](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j)
- React Server Components 的服务端函数存在高风险公告，当前锁定版本需要评估升级及框架兼容。官方公告列出修复版本 19.2.8；不能只更新一个 React 相关包而忽略 peer 兼容。[维护方公告](https://github.com/advisories/GHSA-wx67-qw84-cm4g)
- Capacitor CLI 链路中的 tar 属于工具链风险，涉及解压输入。审计建议的 CLI 升级跨主版本，需要与安卓工程、Java、SDK 和插件一起验证，不能盲目替换底层依赖。[维护方公告](https://github.com/advisories/GHSA-23hp-3jrh-7fpw)
- 其他高风险记录包括 Cloudflare 开发工具、网络库、图片处理和文件匹配链路，需分组处理，而不是执行强制修复或接受审计建议中的不合理降级。

## 发布限制与下一步

本轮修复提交后运行现有 CI。CI 成功只证明它实际覆盖的类型、代码规则、静态功能检查、版本单元测试、构建和源码导出，不代表真实 AI 写入、真机安装或安全风险已经验收。

安全升级和兼容验证完成前保留草稿 PR，不合并到主分支，不标记可用于正式环境，不制作公开正式 APK，不提交应用商店。

下一轮优先对运行依赖与 React / 框架兼容做分组升级，在独立环境验证后再决定是否部署；原签名材料和私人数据继续保留。
