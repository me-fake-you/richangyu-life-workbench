## 正文

最近和 AI 一起打磨了一个个人生活工作台，叫「日常屿」。

我想解决一个很普通的问题：明天想做什么，和今天已经做了什么，总是散在不同的地方。

所以把日程、生活记录和兼职管理放在一起。正在打磨的 AI 功能会先把一句话整理成预览，比如“明天下午两点到四点做兼职”，我核对日期和时间，再确认保存。

它不会因为一句含糊的话就直接改数据。兼职的钱还没到账，也应该和已经收到的钱分开。

代码已经在 GitHub 按 MIT 开源。目前是网页 / PWA，最新 AI 代码仍在开发分支，完整检查还有待解决的问题；原生安卓体验继续开发，尚未上架。公开演示用虚构数据，不需要提供个人信息。

你更需要日程规划、生活记录，还是兼职管理？

GitHub：me-fake-you/richangyu-life-workbench

## 六张图的顺序建议

1. 使用竖版封面。
2. 工作台概念示意，注明虚构数据。
3. “未来安排”和“过去记录”的区别。
4. 确认流程示意，突出“预览不等于保存”。
5. 开源信息与当前限制，不夸大安卓或 AI 完成度。
6. 问读者最需要哪项功能，邀请到 GitHub 反馈。

第 3、5、6 张可以做文字排版；本轮只制作上述三张 SVG，不宣称六张图片全部制作完成。
