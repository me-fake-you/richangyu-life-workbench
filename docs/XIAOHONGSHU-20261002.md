## 推荐发布文案

最近和 AI 一起打磨了一个生活工作台，叫「日常屿」。

想解决的不是再多装一个工具，而是把“准备做的事”和“已经发生的事”放在一起。

比如说：“明天下午两点到四点做兼职。”AI 先整理成日程预览，我核对后再确认保存。已经做完的事，则整理成生活记录；说得不清楚时先补问，不直接乱添加。

项目已在 GitHub 按 MIT 开源。目前支持网页和 PWA，AI 升级代码还在开发分支，原生安卓体验继续打磨，尚未上架。AI 可以接入免费额度，但不是无限免费。

这次先分享开发过程，也想听听：你更需要日程规划、生活记录，还是兼职管理？

## 发布前的边界

- 可以说“代码已按 MIT 开源”，不要说“个人数据已公开”。
- 可以说“AI 先生成预览再由用户确认”，不要说“AI 无误且自动处理所有事情”。
- 可以说“可接入免费额度”，不要承诺永久免费、无限调用或所有部署都零成本。额度按供应商与账号情况变化。[Groq 官方说明](https://console.groq.com/docs/rate-limits)
- 可以说“安卓体验持续打磨”，不要使用“已上架”“正式原生版随便下载”等未经验证的承诺。
- 不把当前个人私有工作台地址、API 密钥、验证码或真实备份放到正文、图片、二维码或评论里。
- 不暗示维护者提供公开账号、无限服务器资源或已开放公众注册。
- 本文没有代为发布小红书，也没有改动个人工作台的访问范围。

## 后续怎么收集反馈

先问用户最想解决哪件事，再按反馈数量和真实使用价值排序。首批重点关注：第一次能否顺利开始、手机是否顺手、AI 是否理解、确认前能否修改、保存是否有清楚反馈。

发布后可整理反馈，但不会未经授权收集私信、读取用户私人数据或自动营销。
